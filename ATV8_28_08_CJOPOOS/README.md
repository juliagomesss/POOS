# Sistema de Cadastro de Pessoas

Sistema desktop simples para cadastro de pessoas com validações e consulta de CEP.

## Funcionalidades

- Cadastro com campos: Nome, CPF/CNPJ, E-mail, Celular e Endereço completo
- Validação de CPF, CNPJ, E-mail, Celular e CEP
- Consulta automática de endereço via CEP (API ViaCEP)
- Armazenamento local em SQLite
- Interface simples e intuitiva

##  Como Executar:
Abra o terminal e execute:
pip install PySide6 requests
