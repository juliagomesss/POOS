# Sistema de Cadastro de Pessoas

Aplicação desktop desenvolvida com Python e PySide6 para cadastro de pessoas com validação de dados e consulta automática de CEP.

# Funcionalidades

- Cadastro de pessoas com campos: Nome, CPF/CNPJ, Email, Celular e Endereço completo
- Validação de todos os campos (CPF, CNPJ, Email, Celular, CEP)
- Consulta automática de endereço via API ViaCEP
- Máscaras automáticas para CPF/CNPJ, Celular e CEP
- Listagem de todos os cadastros em tabela
- Deleção de cadastros com confirmação
- Feedback visual claro para o usuário
- Interface organizada e intuitiva

# Requisitos

- Python 3.8 ou superior
- Pip (gerenciador de pacotes Python)
